# Zettelkasten TUI

A minimal terminal-based editor for building a Zettelkasten through **atomic notes**, **deliberate writing**, and **time**, not automation.

This project focuses on creating the right *conditions for thinking*:
- fast note creation
- low visual noise
- no forced structure
- no AI-generated content

Structure and connections are expected to **emerge naturally from use**.

---

## Philosophy

This tool follows a strict interpretation of the Zettelkasten method:

- Notes are **atomic** (one idea per note)
- Notes are written in your **own words**
- Notes represent **reusable knowledge**, not tasks or logs
- Links and structure are added only when they feel meaningful

This is **not**:
- a task manager
- a daily journal
- a bookmarking tool
- an AI-assisted writing app

Those concerns are intentionally kept separate.

---

## Features

- Terminal UI built with Ink
- Fast keyboard-driven editing
- Atomic note creation with unique IDs
- Local file-based storage
- Calm, distraction-free interface
- Designed to work well over long periods of use

No folders.  
No forced linking.  
No graphs.  

---

## What this tool is best for

- Writing distilled ideas
- Capturing insights after reflection
- Developing a personal knowledge system over time
- Thinking in public or private through text

---

## What this tool intentionally avoids

- Automatic linking
- AI-generated notes
- Premature structure
- Mixing tasks or daily logs with knowledge notes

If something is not yet knowledge, it probably does not belong here.

---

## Recommended workflow

1. Reflect on an idea
2. Write it as a complete sentence in your own words
3. Keep it small and focused
4. Let connections emerge naturally as you revisit notes

---

## Status

This project is actively evolving and opinionated by design.
Features are added only when they support long-term thinking quality.

Contributions are welcome — especially those that improve clarity, stability, or ergonomics without increasing cognitive noise.
