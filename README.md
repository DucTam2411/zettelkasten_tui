# Zettelkasten TUI

A minimal terminal-based Zettelkasten editor built with Ink.

Designed for writing **atomic notes** with focus and low distraction.
No folders, no AI, no forced structure.

Notes are kept local.
Connections and structure are expected to emerge naturally over time.

Keyboard-driven, calm, and opinionated.

Early but usable.
